# Browser Agent

Prioridade:
DOM/API > Accessibility > Vision fallback.

Capacidades:
- abrir URL;
- ler DOM;
- encontrar;
- clicar;
- preencher;
- selecionar;
- navegar;
- rolar;
- trocar aba;
- download;
- upload;
- extrair;
- verificar.

## Regra

Ação não termina no clique.

Termina quando o resultado esperado é confirmado.

## Recovery

Se algo falhar:
- reconsultar DOM;
- reanalisar página;
- procurar alternativa;
- usar visão apenas como fallback.

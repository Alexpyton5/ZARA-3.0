# Definition of Done

Um módulo só está concluído quando:
- compila;
- possui tratamento de erro;
- não simula sucesso;
- possui testes adequados;
- funciona no Electron;
- respeita permissões;
- registra execução quando necessário;
- possui fallback;
- não quebra build;
- não cria regressão crítica;
- documentação está atualizada.

## UI
- calibrada contra MASTER;
- screenshot fora de produção;
- dados reais;
- loading/success/error;
- acessibilidade mínima.

## Tool
- schema de entrada;
- schema de saída;
- timeout;
- erro explícito;
- verifier;
- risk level.

# Skills e pesquisas

## Skills

Uma skill precisa passar por:

```text
DRAFT → TESTING → READY → ACTIVE → RETIRED
```

Toda skill deve declarar objetivo, permissões, versão, checksum, testes e limites. O registro não autoriza execução por si só.

## Pesquisas

Toda pesquisa deve guardar URL, título, trecho, data, pesquisador, relevância e hash da evidência. Fontes ainda não revisadas não devem virar instrução operacional.

## Template de pesquisa

```text
### Título
- URL:
- Capturado em:
- Pesquisador:
- Relevância:
- Evidência:
- Estado: NEW | REVIEWED | REJECTED | ADOPTED
- Próximo passo:
```
